# Personal Profile Page

A simple personal profile webpage built using **semantic HTML**.

##  About

This project was created to practice the fundamentals of HTML and understand how to structure a webpage using meaningful semantic elements.

##  Technologies Used

- HTML5

## 📚Concepts Practiced

- Basic HTML document structure
- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<body>`
- Meta tags
- `<title>`
- `<header>`
- `<main>`
- `<section>`
- Headings
- Paragraphs
- Unordered lists
- List items
- Links using `<a>`
- HTML attributes such as `href` and `target`

##  Page Sections

The profile page contains:

- **Header** – Name and professional role
- **About Me** – Short personal introduction
- **Skills** – List of technical skills
- **Contact Me** – Email, phone number, and LinkedIn profile

##  Objective

The goal of this project is to demonstrate proper semantic HTML structure and the correct use of HTML elements and attributes.

##  How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the HTML file in a browser.
4. You can also use the **Live Server** extension in VS Code.
